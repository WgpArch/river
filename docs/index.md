# 🏠 Welcome to my River Config

A dynamic tiling Wayland compositor setup on Arch Linux. This configuration uses the `filtile` layout generator for a 50/50 autotiling split, features a Catppuccin-inspired color scheme, and integrates custom Waybar modules, Rofi launchers, and utility scripts.

![River Showcase](screenshots/screenshot-20260524-195531.png)

## ✨ Highlights
- **Layout:** `filtile` autotiling with 50/50 split, easily adjustable via keybinds.
- **Aesthetics:** Catppuccin Mocha border colors (Yellow focused, Green unfocused) against a dark base.
- **Custom Waybar:** 11 persistent tags, live weather module, media player, and hardware monitors.
- **Rofi Integration:** Cyber-neon themed app launcher, power menu, and music controller.
