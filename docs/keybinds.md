# ⌨️ Keybinds

Here are the default keybindings for this River setup. The main modifier key is `Super`.

## 🖥️ Programs & System

| Keybind | Action |
| :--- | :--- |
| `Super + D` | Open App Launcher (Rofi cyber-neon) |
| `Super + E` | Open Power Menu (Rofi) |
| `Super + Q` | Close focused view |
| `Super + R` | Reload River config |
| `Super + Shift + E` | Exit River |
| `Super + Space` | Toggle floating |
| `Super + F` | Toggle fullscreen |

## 🔍 Focus & Movement

| Keybind | Action |
| :--- | :--- |
| `Super + J / K` | Focus next/previous view |
| `Super + Shift + J / K` | Swap next/previous view |
| `Super + Period / Comma` | Focus next/previous output |
| `Super + Shift + Period / Comma` | Send view to next/previous output |
| `Super + Shift + Return` | Bump view to top of stack (Zoom) |

## 🗂️ Tags (Workspaces)

| Keybind | Action |
| :--- | :--- |
| `Super + [1-9]` | Focus tag 1-9 |
| `Super + Shift + [1-9]` | Move view to tag 1-9 |
| `Super + 0` | Focus all tags |
| `Super + Shift + 0` | Move view to all tags |
| `Super + P` | Toggle scratchpad (Tag 21) |
| `Super + Shift + P` | Move view to scratchpad |

## 📐 Layout Controls (filtile)

| Keybind | Action |
| :--- | :--- |
| `Super + H / L` | Decrease/Increase main ratio |
| `Super + Shift + H / L` | Decrease/Increase main count |
| `Super + Arrow Keys` | Set main location (Top/Right/Bottom/Left) |
| `Super + M` | Set monocle layout |
| `Super + Shift + A` | Reset main ratio to 50% |

## 🖱️ Mouse & Media

| Keybind | Action |
| :--- | :--- |
| `Super + Left Click` | Move view |
| `Super + Right Click` | Resize view |
| `Super + Middle Click` | Toggle float |
| `Print` | Take screenshot |
| `Super + Print` | Screen record (Rofi menu) |
| `Super + C` | Color picker script |
| `Super + X` | Rofi music menu |
| `Volume Keys` | Volume up/down/mute (`wpctl`) |
